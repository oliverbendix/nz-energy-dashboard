# nz-energy-dashboard
Renewable energy insights dashboard for Aotearoa - a personal demo project

## Who built this?

Oliver Thompson. Keen technologist, strategist, general player with tech and data.

## Why'd I build this?
I built this to keep myself current with a number of tools:
- Cloud-based data engineering (storage in AWS, ETL, transformation).  
- Building reproducible data pipelines in Databricks.  
- Visualising sustainability-focused insights for a NZ gentailer context.  
- Applying **data governance concepts** (lineage, raw/silver/gold layers).
